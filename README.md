# Apple Music TV7

**Apple Music TV 7.0 风格的 Android TV 客户端。**

本仓库只用于**分发安装包与更新日志**。项目闭源，源代码不公开。

---

## 下载

前往 **[Releases](../../releases)** 页面下载最新的 `AppleMusicTV7-x.x.x-debug.apk`。

| 项目 | 值 |
|---|---|
| 应用名 | Apple Music TV7 |
| 包名 | `music7.app` |
| 最低系统 | Android 9 (API 28) |
| 架构 | arm64-v8a / armeabi-v7a / x86_64 |
| 体积 | 约 50 MB |

## 安装

```bash
adb install -r AppleMusicTV7-0.1.0-debug.apk
```

或把 APK 拷进 U 盘 / 通过当贝市场等工具侧载到电视盒子、投影仪。

## 功能

- **Apple TV 7.0 界面复刻**：顶栏胶囊导航、横向滚动内容架、底部悬浮音乐胶囊
- **完整遥控器焦点体系**：上下左右、返回三级语义、进入/退出播放器自动恢复焦点
- **搜索**：一级分类网格（5×4）→ 二级实时输入与结果，支持艺人 / 歌曲 / 专辑 / 建议词
- **侧边栏**：主页、浏览、广播、资料库、搜索 + 底部账户入口，未登录直接弹二维码扫码登录
- **播放器**：歌词滚动、队列面板、封面动效、音频频谱
- **设置**：资料库写入开关、播放列表倒序、低性能模式、音频质量、杜比全景声、封面动效、频谱权限、磁盘缓存与清除缓存

- 本项目为个人学习与自用作品，与 Apple Inc. 无任何关联。
